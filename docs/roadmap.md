# Roadmap

1. **Foundation (current):** local WebSocket connection, Electron UI, simulated progressive answer, tests and documentation.
2. **Audio capture:** Windows WASAPI loopback with explicit start/stop control and an in-app level meter. Bounded PCM delivery for transcription remains next.
3. **Transcription:** VAD, buffers, faster-whisper and partial results.
4. **Intelligence:** measurable local question detector and Ollama streaming.
5. **Hybrid mode:** explicit opt-in external providers and model selection.
6. **Benchmark/release:** latency measurement, packaging and open-source release preparation.

No roadmap item is implicitly enabled by the current UI.
